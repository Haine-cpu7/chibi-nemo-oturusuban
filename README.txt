ちびねものおるすばん大作戦！ WEB公開版 v1.0
=================================================

【この版について】
採用UI：v0.3（ピンク×水色のかわいいタイトル画面版）
GitHub Pages でそのまま公開できます。

【ローカルで遊ぶ】
このフォルダを展開した状態で index.html をダブルクリックしてください。
※ ZIPの中から直接 index.html を開かないでください。

【GitHub Pages 公開手順】
1. GitHubで新しいリポジトリを作成
   例：chibi-nemo-oturusuban
2. このフォルダ内のファイルを、リポジトリの一番上（root）へアップロード
   - index.html
   - style.css
   - script.js
   - assets/
   - .nojekyll
3. GitHub の Settings → Pages
4. Build and deployment を「Deploy from a branch」に設定
5. Branch：main / (root) → Save
6. 数分待つと公開URLが表示されます。

【重要】
GitHub上で index.html がリポジトリ直下に見えていればOKです。
「chibi-nemo-web-v1.0-v03/index.html」のように余計な親フォルダを作らないでください。

【保存】
プレイ回数・最高たのしさ等はブラウザの localStorage に保存されます。
サーバー・データベースは不要です。
